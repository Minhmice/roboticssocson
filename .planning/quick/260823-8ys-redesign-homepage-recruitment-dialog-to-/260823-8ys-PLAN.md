# Redesign homepage recruitment dialog

## Objective

Replace the current generic orange/red recruitment modal composition with a focused, bilingual recruitment briefing that uses the established Robotics Sóc Sơn arena-black, pit-slate, HUD-cyan, logo, and restrained competition-floor visual language.

## Constraints

- Preserve the Radix Dialog primitive, homepage mount, 24-hour localStorage policy, route `/recruitment`, existing localized keys, and accessible close behavior.
- Preserve the existing dark competition-floor brand rather than inventing a new palette.
- Keep the dialog concise and clear for a first-visit interruption: one primary message, one supporting visual, one primary CTA, one dismiss action.
- Use existing local imagery/assets only; no new dependency or fake illustration.
- Motion must explain modal arrival and hierarchy, respect reduced motion, and animate compositor-friendly properties.

## Tasks

### Task 1: Recompose the recruitment dialog

Files: `src/components/homepage/RecruitmentDialog.tsx`, `src/components/ui/dialog.tsx` if needed.

- Replace the orange/red banner treatment with a dark briefing-room composition: visual asset panel, cyan signal accent, concise title/message block, and separated action row.
- Use the existing logo and a relevant local team/robot image if available.
- Remove generic decorative gradients, unnecessary icon noise, and duplicated visual labels.
- Keep Vietnamese/English copy from existing messages and preserve CTA intent.
- Keep mobile layout readable with short content width, safe dialog height, and stacked actions.

### Task 2: Refine motion and interaction polish

Files: `src/components/homepage/RecruitmentDialog.tsx`, `src/components/ui/dialog.tsx`, `src/app/globals.css` only if necessary.

- Use a purposeful modal entrance: backdrop opacity plus centered surface opacity/scale/translate, with a restrained competition-light detail.
- Make close, dismiss, and primary CTA states tactile with accessible focus rings and reduced-motion fallback.
- Avoid animating layout properties and avoid generic continuous loops.

### Task 3: Verify

- Run `npm run lint`, `npm run build`, `npm run check:assets`.
- Run design detector on edited files.
- Inspect homepage dialog in browser at desktop and mobile widths, including first-visit auto-open and reduced-motion-safe structure.
