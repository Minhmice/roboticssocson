## Thiết lập môi trường lập trình FTC Java với Android Studio

Lập trình robot FIRST Tech Challenge (FTC) bằng Java trong Android Studio mang lại khả năng kiểm soát mã nguồn bằng Git, gợi ý cú pháp mạnh mẽ, tái sử dụng các thư viện nâng cao (như Road Runner, FTCLib, OpenCV/EasyOpenCV) và khả năng gỡ lỗi trực tiếp trên phần cứng REV Control Hub.

![Môi trường lập trình Android Studio](https://upload.wikimedia.org/wikipedia/commons/9/95/Android_Studio_Workspace.png)

### Yêu cầu cài đặt phần mềm và JDK

Trước khi bắt đầu, máy tính phát triển cần chuẩn bị các gói công cụ tiêu chuẩn sau:

1. **Android Studio:** Tải bản phát hành ổn định chính thức (ví dụ Ladybug hoặc Hedgehog) từ trang chủ Android Developer.
2. **Java Development Kit (JDK):** FTC SDK hiện tại yêu cầu OpenJDK 17. Android Studio đi kèm sẵn JetBrains Runtime tích hợp sẵn JDK 17, giúp tránh xung đột biến môi trường máy chủ.
3. **Android SDK Platforms:** Mở SDK Manager trong Android Studio và đảm bảo đã cài đặt:
   - Android SDK Platform 34 (hoặc phiên bản chỉ định trong file `build.common.gradle` của SDK).
   - Android SDK Build-Tools và Android SDK Command-line Tools.
4. **Git CLI:** Cài đặt Git để đồng bộ phiên bản mã nguồn với kho chứa của đội.

### Tải và import FtcRobotController SDK

Kho lưu trữ FTC SDK chứa mã nguồn mẫu cùng toàn bộ module thư viện lõi của FIRST. Để khởi tạo dự án:

```bash
# Clone kho mã nguồn chính thức từ GitHub
git clone https://github.com/FIRST-Tech-Challenge/FtcRobotController.git
cd FtcRobotController
```

Trong Android Studio:
1. Chọn **File -> Open...** và duyệt đến thư mục `FtcRobotController` vừa clone.
2. Đợi Gradle hoàn tất quá trình tải các gói phụ thuộc (Gradle Sync). Nếu gặp thông báo thiếu đường dẫn Android SDK, kiểm tra file `local.properties` tại thư mục gốc dự án:
   ```properties
   ## Windows:
   sdk.dir=C\:\\Users\\<UserName>\\AppData\\Local\\Android\\Sdk
   ## macOS/Linux:
   # sdk.dir=/Users/<UserName>/Library/Android/sdk
   ```
3. Mọi mã nguồn phát triển bởi đội phải được đặt bên trong module `TeamCode`, cụ thể tại đường dẫn:
   `TeamCode/src/main/java/org/firstinspires/ftc/teamcode/`.

### Nạp code qua USB và kết nối Wi-Fi ADB không dây

REV Control Hub chạy hệ điều hành nhúng Android, cho phép nạp mã nhị phân thông qua giao thức ADB (Android Debug Bridge).

```text
[Máy tính lập trình]
         │ (Kết nối vào Wi-Fi mạng Robot: DIRECT-xxxx hoặc ControlHub-xxxx)
         ▼
[Địa chỉ IP Control Hub mặc định: 192.168.43.1]
         │
    Port 5555 (ADB Daemon)
         │
[Android Debug Bridge nạp file TeamCode-debug.apk]
```

Để thiết lập nạp không dây qua Wi-Fi:
1. Kết nối Wi-Fi của máy tính vào mạng Wi-Fi phát ra từ REV Control Hub (mật khẩu mặc định thường là `password`).
2. Mở cửa sổ Terminal trong Android Studio và thực thi lệnh:
   ```bash
   adb connect 192.168.43.1:5555
   ```
3. Khi terminal phản hồi `connected to 192.168.43.1:5555`, tên thiết bị Control Hub sẽ xuất hiện trên thanh công cụ triển khai (Run Target toolbar) của Android Studio.

### Khởi tạo LinearOpMode mẫu đầu tiên

Tạo file mới `BasicAutonomous.java` bên trong thư mục `TeamCode/.../teamcode/`:

```java
package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.eventloop.opmode.LinearOpMode;
import com.qualcomm.robotcore.eventloop.opmode.TeleOp;
import com.qualcomm.robotcore.hardware.DcMotor;

@TeleOp(name = "Co Ban: Kiem Tra Dong Co", group = "LinearOpMode")
public class BasicAutonomous extends LinearOpMode {
    private DcMotor leftDrive;
    private DcMotor rightDrive;

    @Override
    public void runOpMode() {
        // Ánh xạ phần cứng tương ứng tên cấu hình trong Driver Station
        leftDrive = hardwareMap.get(DcMotor.class, "left_drive");
        rightDrive = hardwareMap.get(DcMotor.class, "right_drive");

        // Đảo chiều động cơ bên phải theo quy chuẩn cơ khí chassis
        leftDrive.setDirection(DcMotor.Direction.FORWARD);
        rightDrive.setDirection(DcMotor.Direction.REVERSE);

        telemetry.addData("Trang Thai", "Da khoi tao, cho nut Init...");
        telemetry.update();

        // Chờ tín hiệu Start từ Driver Station
        waitForStart();

        // Vòng lặp điều khiển chính trong suốt trận đấu
        while (opModeIsActive()) {
            telemetry.addData("Trang Thai", "Robot dang hoat dong");
            telemetry.update();
        }
    }
}
```

Nhấn nút **Run 'TeamCode'** (biểu tượng Play màu xanh lá) để biên dịch và nạp trực tiếp vào Robot Controller. Chọn OpMode vừa tạo trên bảng điều khiển Driver Station để sẵn sàng thử nghiệm.
