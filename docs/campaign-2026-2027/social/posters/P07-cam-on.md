# P07 — Mẫu cảm ơn

Có 2 mẫu. Lần đầu đăng ngày 22/11 (sau mốc đợt 1), sau đó đăng mỗi khi có nhà tài trợ mới hoặc vào Chủ nhật cuối mỗi đợt.

## Mẫu A — Cảm ơn người ủng hộ cá nhân (1080×1350)

```
┌──────────────────────────────┐
│ [logo]          CẢM ƠN TUẦN N│
│  CẢM ƠN                      │
│  N MẢNH GHÉP                 │  ← N = số người ủng hộ trong tuần
│  ────────────────────────    │
│  Nguyễn V** A · Trần T** B · │  ← tên che theo NĐ 13/2023
│  Lê H** C · Phạm Q** D · …   │     chỉ ghi người đã đồng ý công khai
│  ────────────────────────    │
│  Tổng tuần: X.XXX.XXX ₫       │
│  Đã có: XX.XXX.XXX / 33.975.000 ₫ │
│ BUILD THE NEXT ROBOT · /support │
└──────────────────────────────┘
```

- **Không ghi số tiền của từng người**, chỉ ghi tổng tuần.
- Tên che theo dạng `Nguyễn V** A`. Ai không muốn hiện tên thì ghi "Một người bạn".
- Nhiều tên quá thì làm thành carousel, mỗi ảnh tối đa 30 tên.

## Mẫu B — Vinh danh nhà tài trợ doanh nghiệp (1080×1350)

```
┌──────────────────────────────┐
│ [logo RBS]  ×  [logo DN]     │
│                              │
│  CẢM ƠN                      │
│  [TÊN DOANH NGHIỆP]          │
│  đã đồng hành cùng           │
│  Robotics Sóc Sơn #39256     │
│ ┌──────────────────────────┐ │
│ │ Gói Vàng · 10.000.000 ₫  │ │  ← chỉ ghi số tiền khi DN đồng ý
│ │ → Bộ não robot (M1)      │ │  ← tiền dùng vào mission nào
│ └──────────────────────────┘ │
│  "Câu trích của đại diện DN" │  ← nếu có
│ BUILD THE NEXT ROBOT · /support │
└──────────────────────────────┘
```

- Gửi bản nháp cho doanh nghiệp duyệt trước khi đăng: kiểm tra logo, tên, số tiền.
- Quyền lợi theo từng gói: [../../05-goi-tai-tro-doanh-nghiep.md](../../05-goi-tai-tro-doanh-nghiep.md).
- Ghi là **"đồng hành cùng Robotics Sóc Sơn"**, không ghi "nhà tài trợ của FIRST" ([../../10-support-thanh-toan-phap-ly.md](../../10-support-thanh-toan-phap-ly.md) §6).
